SEPA Generator Community 1.4.1

A maintenance update. SEPA file generation, validation and supported formats are unchanged from 1.4.0, and payment files are still processed locally on your computer.

Linux installation

  • The DEB package integrates better with the desktop: SEPA Generator Community appears in the applications menu with its own icon, and the running window is associated with that launcher.
  • Software centres that read AppStream metadata now show the application name, description and publisher.
  • The package installs on both older and newer Debian and Ubuntu releases, which use different names for the audio library package.

Guides

  • Help > Online guides and the Guides link in the footer now open the Community section of the guides on the product website.
