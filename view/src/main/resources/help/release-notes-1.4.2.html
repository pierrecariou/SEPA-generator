SEPA Generator Community 1.4.2

A maintenance update for initiating party identification. Payment files are still processed locally on your computer.

Initiating party identifier

  • The initiating party identifier in Settings is now optional and is no longer limited to a French SIRET. Enter any organisation identifier your bank requires, or leave it blank to write the initiating party name only.
  • You can add an optional scheme (an ISO code such as BANK or CUST, or a proprietary scheme name) and an optional issuer. pain.001.001.03 and .09 write both.
  • pain.001.001.02 has no place for a scheme name. When a scheme is configured and that format is selected, a short note explains that the scheme is left out; the identifier and issuer are still written.
  • Existing settings keep working: a saved SIRET produces the same XML as before.

Suggested file name

  • The save dialog now suggests a bank-neutral name such as 20261026_145200_PAIN001.xml. You can still choose any name.

Other SEPA generation behaviour is unchanged.
