SEPA Generator Community 1.4.0

This release focuses on the correctness of the files you generate, clearer feedback when something is wrong, and a calmer interface. Payment files are processed locally on your computer: they are read, validated and written on your machine, and are never uploaded by SEPA Generator.

Generation correctness

  • CSV files are now read as UTF-8, with a byte order mark handled transparently. Accented and non-Latin characters are also preserved when importing XLS and XLSX files.
  • IBANs are checked against the registered country list, the country's official IBAN length and the checksum, and are normalised so the value that is validated is exactly the value that is written.
  • Amounts, batch totals and the control sum are computed with exact decimal arithmetic, so the totals in the file always match the sum of its transactions.
  • Amount and text-length limits follow the SEPA rules for party names and structured address fields.
  • Characters that are not legal in XML 1.0 are detected before anything is written: generation stops with a clear message instead of producing invalid XML.
  • Corrected XML structure and field mapping for pain.001.001.02 and pain.001.001.09.
  • Generate pain.001.001.03 Credit Transfer files for banks and upload channels that still require the legacy format. pain.001.001.09 remains the modern recommended format.

Clearer errors

  • All problems in an input file are now reported together, each naming the row and the field it comes from, instead of stopping at the first one.
  • The generation failure window was redesigned: a clear summary and the full list of validation issues in a compact, scrollable area.

Import

  • Hardened CSV, XLS and XLSX reading, including spreadsheet cells that contain commas or other separator characters.

Update notification

  • The application checks once a day whether a newer Community version is available and shows a discreet indicator in the header when there is one.
  • Help > Check for updates lets you check whenever you want.
  • Updating stays in your hands: the application opens the download page in your browser and never downloads or installs anything by itself. If the update service cannot be reached, the check does not interrupt your work.

Interface

  • The main window is organised in clearer sections, with a more readable generation summary once a file has been produced.
  • The window now opens at a size that fits the available screen.
  • A new Help menu gathers what's new, the update check, contact and product information.
  • Continued light and dark theme polish, and a simplified footer.
  • Clearer publisher identity: the About dialog, application footer and command-line help now consistently identify SEPA Generator Community as published by Niryosys.

Reliability

  • An interrupted or failed save leaves your previously saved settings intact.

Installation

  • Packaged downloads for Windows (MSI), macOS on Apple Silicon and Intel (DMG) and Linux (DEB). Each package bundles its own Java runtime, so no separate Java installation is required.
  • SEPA Generator Community generates SEPA Credit Transfers; it does not generate direct debits.
